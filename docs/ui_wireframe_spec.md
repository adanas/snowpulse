## 1. UI/UX設計のキーコンセプト

1. **グローブ対応（Fat-Finger Design）**:
   - ゲレンデ上でグローブをつけたままでも押し間違えないよう、主要ボタン（計測開始・停止）の高さは最低 56dp〜64dp 以上を確保。
   - 画面を見ずにポケットの上からでも操作できるよう、ハードウェア音量ボタンへのショートカット（長押しで一時停止/再開）をサポート。
2. **雪上ハイコントラスト（Glanceability）**:
   - 白銀の世界や強い日光下でも視認しやすい「ダークテーマ ＋ 蛍光カラー（シアン・アンバー・ネオングリーン）」を採用。
   - 瞬時に読み取れるよう、走行中の速度表示は 72sp クラスの極太フォントを中央配置。
3. **滑走とリフトの自動モード遷移**:
   - ユーザーが滑走終了ボタンを手動で押さなくても、リフト搭乗を検知した時点でランを自動集計・完了表示に切り替え。

## 2. 画面構成とコンポーネント

```
[画面遷移フロー]
ホーム / 履歴画面 (③)
    │
    ▼ (「滑走計測スタート」タップ)
滑走中トラッキング画面 (①) ──(リフト乗車検知 or 終了)──> ラン分析・詳細画面 (②)
    │                                                      │
    └───────────────────(保存して戻る)───────────────────────┘
```

### ① 滑走中画面 (Tracking Screen)
滑走中にポケットから取り出してチラ見した際の視認性を最優先した画面。
- **ステータスバッジ**: 現在のステート（滑走中 / リフト搭乗中 / 休憩中）をパルスアニメーション付きで明示。
- **大型スピードメーター**: 現在速度（km/h）と本日の最高速度。
- **モーションウィジェット**:
  - **推定エッジ角（傾斜角）**: ターン中の深いエッジングをグラフィカルにゲージ表示。
  - **直近トリック判定**: 「Ollie 180 / 滞空 0.65s」など、直近で決めたアクションをリアルタイム表示。
- **ビッグアクションボタン**: 「一時停止」「滑走終了」の巨大ボタン。

### ② ラン分析・詳細画面 (Run Detail & Analysis)
1本の滑走（Run）が終わった後、リフトの上や休憩中に振り返るための詳細画面。
- **GPS 3Dマップ軌跡**:
  - 滑走ライン上に「最高速度到達点」や「トリック発生地点（★アイコン）」をプロット。
- **モーション＆トリックレポート**:
  - 滞空時間、推定ジャンプ高、スピン回転数（360など）、着地成否の一覧。
- **雪質・振動インジケータ**:
  - 「圧雪」「パウダー」「荒れバーン」の推定結果と注意箇所のメモ。
- **SNSシェア / エクスポート**:
  - 滑走サマリー画像を1タップでInstagramやXに投稿可能なカード形式で生成。

### ③ ホーム / ダッシュボード画面 (Dashboard Screen)
1日の始まりや滞在中の状況を確認するベース画面。
- **現在地のゲレンデ気象（Resort Weather Card）**:
  - 天候アイコン（❄️）、現在気温（山麓・山頂）、24時間新雪量（cm）、積雪深（cm）、風速・風向、雪質コンディション（極上ドライパウダー/圧雪）。
- **Today's Summary カード**: 本日の総滑走距離、最高速度、総獲得標高、滑走本数。
- **メインCTA**: 「check in」特大ボタン。
- **ラン履歴リスト**: Run #1〜#N の距離・最高速・最大エッジ角一覧。
- **ギア設定導線**: 右上の設定アイコンから設定画面へ遷移可能。

### ④ ギア・収納位置設定画面 (Settings Screen)
いつでもスタンスや端末の収納場所を再設定できる画面。
- **スタンス切り替え**: Regular（左足前）/ Goofy（右足前）のワンタップトグル。
- **スマホ収納位置セレクター**:
  - パンツポケット（前足側）【推奨】: ボード角付けと連動しフル機能動作。
  - パンツポケット（後足側）
  - ジャケット胸ポケット: 上半身の傾斜角（体幹角）として参考表示。
  - リュック / ヒップバッグ: 速度・高度ログのみ（姿勢解析OFF）。
- **自動キャリブレーション状態表示**: 変更後も最初の直進滑走で自動的に座標軸を補正する旨を明記。

## 3. 現在地のゲレンデ天気情報 UI検討パターン

[wireframe.html](file:///Users/sanada_a/.gemini/antigravity/brain/55406dc5-3a38-4785-977f-ee79031cca4c/wireframe.html) にて以下の3パターンをインタラクティブに切り替えてご確認いただけます：

| パターン | 特徴 | 適した利用シーン |
| :--- | :--- | :--- |
| **パターンA（推奨）: 総合カード型** | 気温（山麓・山頂）、粉雪ステータス、24h新雪（+18cm）、積雪深、風速、雪質バッジを1つの美しいカードに集約 | 朝イチのコンディション把握に最も役立ち、視認性が高い |
| **パターンB: コンパクト型** | ヘッダー付近に気温・新雪・風速をピルバッジとして横並び表示 | 縦スクロール領域を圧迫せず、他のコンテンツを広く見せたい場合に最適 |
| **パターンC: 3h推移タイムライン型** | 現在の気象に加え、今・12:00・15:00・18:00の天気・気温・降雪量予測推移を表示 | 午後の天候急変や新雪の降り積もりを予測しながら滑りたいヘビーユーザー向け |
